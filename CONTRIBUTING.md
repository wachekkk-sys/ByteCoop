# Contributing

Thanks for your interest in ByteCoop.

**Current state:** The public repository is a documentation and project showcase. The installable prototype source has not yet been published. You can already contribute useful feedback and design/architecture ideas.

## Useful feedback

- Describe a real problem you face when working across multiple AI models.
- Give a reproducible example of missing or irrelevant project context.
- Suggest ways to preserve non-developer simplicity while enabling advanced workflows.
- Report a documentation issue, discrepancy or missing limitation.

Open an issue with a clear title, expected behavior and actual behavior. Redact secrets, personal data, proprietary prompts and private company information.

## For upcoming source contributions

Once source publication and licensing are finalized, the expected workflow will be: focused changes, regression tests and human review before merging. The release will document environment requirements and a precise contribution policy.

**Security issues:** follow [SECURITY.md](SECURITY.md). Never put exploit details or keys in public issues.
